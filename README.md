# caguastrava

caguastrava es una app social inspirada en Strava, pero en vez de trackear carreras o rutas en bicicleta, trackea tus salidas de tragos: cocteles, cervezas, destilados y los lugares donde te los tomas.

## ¿Qué hace?

- Registra tus actividades sociales (salidas a bares, cocteles, cervezas, destilados, etc.)
- Permite calificar la bebida y el lugar donde la disfrutaste
- Gamifica la experiencia con puntos, logros y rankings, igual que Strava lo hace con el ejercicio
- Conecta a una comunidad para compartir y comparar tus salidas

## Flujo de trabajo

El desarrollo se organiza a través de issues y pull requests en GitHub:

1. Toda nueva feature, mejora o bug se documenta primero como un issue, describiendo el problema u objetivo.
2. El trabajo se realiza en una rama separada asociada al issue correspondiente.
3. Al completar el trabajo, se abre un pull request que referencia el issue y describe los cambios realizados.
4. El pull request se revisa antes de mergear a la rama principal.
5. Al mergear el pull request, el issue relacionado se cierra automáticamente.
